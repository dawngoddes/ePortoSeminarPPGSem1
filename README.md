# ePortofolio Seminar PPG — Muhammad Fikri Wibowo

Website portofolio digital untuk mendokumentasikan visi dan misi pribadi, refleksi pengalaman belajar Semester 1 dan Semester 2, artefak pembelajaran, serta refleksi komprehensif selama mengikuti Program PPG.

## Menu website

1. **Visi & Misi** — visi pendidikan Indonesia, visi sebagai calon guru Informatika, misi, dan langkah konkret.
2. **Refleksi Semester 1** — pertemuan P2 sampai P7: Filosofi Pendidikan, PPDP, PMA, PPL Mandiri, Growth Mindset, dan Computational Thinking. Artefak Semester 1 tersedia di bagian yang sama.
3. **Refleksi Semester 2** — pertemuan P8 sampai P12: PSE, Pembelajaran Mendalam dan Asesmen Lanjut di SMK, PLP Mandiri, Pendidikan Berkemajuan, dan Proyek Kepemimpinan. Artefak Semester 2 tersedia di bagian yang sama.
4. **Refleksi PPG** — refleksi akhir melalui Lembar Kerja 3 (LK 3), termasuk pandangan tentang pendidikan Indonesia, upaya menjadi guru profesional, dan tiga rencana tindak lanjut.

## Struktur folder

- `index.html` — isi dan struktur website.
- `style.css` — gaya visual dan tampilan responsif.
- `script.js` — navigasi aktif dan menu seluler.
- `pdf/` — dokumen refleksi Semester 1, visi-misi, dan LK 3.
- `pdf/semester2/` — PDF refleksi P8 sampai P12 yang dikonversi dari dokumen Seminar 2.
- `artefak/` — artefak pembelajaran Semester 1 dari repositori ePortofolio sebelumnya.
- `artefak/semester2/` — empat PDF artefak Semester 2 yang dilampirkan.

## Menjalankan dan memperbarui di GitHub Pages

1. Unduh dan ekstrak paket ini.
2. Unggah seluruh **isi folder `ePortoSeminarPPGSem1-main`** ke root repositori GitHub yang digunakan untuk GitHub Pages. Pastikan `index.html`, `style.css`, dan `script.js` berada di root yang sama.
3. Pada GitHub, buka **Settings → Pages** dan pilih sumber deploy yang sesuai dengan repositori (misalnya branch `main` dan folder `/root`).
4. Simpan perubahan dan buka alamat GitHub Pages yang ditampilkan GitHub. Jika situs lama tersimpan di cache, lakukan refresh paksa.

Seluruh tautan dokumen menggunakan path relatif sehingga dapat bekerja ketika folder dipublikasikan sebagai GitHub Pages.

## Catatan arsip

Beberapa nama file artefak PDF berbeda dari judul yang tercetak pada sampul dokumen. Kartu pada website mengikuti informasi sampul bila dapat diperiksa, dan file tetap disertakan agar tidak ada artefak yang terlewat.
